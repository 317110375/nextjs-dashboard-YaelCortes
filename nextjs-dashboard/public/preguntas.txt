1. ¿Qué es Next.js y por qué es el framework de React más popular?
Es un framework de React que permite crear aplicaciones web rápidas con renderizado en el servidor (SSR) y generación de sitios estáticos (SSG). Es popular porque facilita el SEO, el rendimiento y tiene una estructura de carpetas muy organizada.

2. ¿Cuál es el comando exacto con npx para inicializar un proyecto de Next.js asegurando usar la última versión?
npx create-next-app@latest

3. ¿Cuál es el comando utilizado para levantar el entorno de desarrollo y en qué puerto se ejecuta por defecto?
npm run dev. Se ejecuta por defecto en el puerto 3000 (localhost:3000).

4. ¿Qué función cumple el comando npm run build en un proyecto de Next.js?
Compila y optimiza la aplicación para producción, creando una versión lista para ser desplegada en un servidor real.

5. Describe las carpetas /public y /app:
- /public: Guarda archivos estáticos como imágenes, iconos y fuentes que son accesibles directamente por la URL.
- /app: Contiene las rutas, componentes y lógica principal de la aplicación utilizando el App Router.

6. ¿Qué es un CSS MODULE y cómo se usan?
Son archivos CSS donde los estilos tienen alcance local por defecto. Se crean como 'archivo.module.css' y se importan como un objeto en el componente para evitar conflictos de nombres.

7. ¿Qué hace el componente Layout.tsx?
Define una estructura visual compartida para varias páginas (como menús o pies de página). El contenido de cada página se inyecta a través de la propiedad 'children'.

8. ¿Qué es el enrutamiento?
Es el mecanismo que permite al usuario navegar entre diferentes secciones o vistas de una aplicación web a través de la URL.

9. ¿Cuál es la diferencia entre <Image> e <img>?
El componente <Image> de Next.js optimiza automáticamente las imágenes (cambia el tamaño, reduce el peso y usa formatos modernos), mientras que la etiqueta <img> de HTML carga la imagen original sin optimizaciones.

10. ¿Qué es el Lazy Load?
Es una técnica que retrasa la carga de recursos (como imágenes) hasta que son necesarios (por ejemplo, cuando el usuario hace scroll hacia ellas), ahorrando datos y tiempo de carga.

11. Funcionamiento del código de imágenes (Imagen adjunta):
El código usa clases de Tailwind CSS para mostrar imágenes de forma condicional:
- La primera imagen (hero-desktop) tiene 'hidden md:block', por lo que se muestra solo en pantallas grandes (Escritorio).
- La segunda imagen (hero-mobile) tiene 'block md:hidden', por lo que se muestra solo en pantallas pequeñas (Celulares).

12. ¿Cómo funciona el enrutamiento en Next.js?
Funciona a través del sistema de carpetas dentro de /app. Cada carpeta representa un segmento de la URL.

13. ¿Qué es una ruta en contexto web y dónde la vimos?
Es la dirección específica (URL) que solicita el navegador. Lo vimos al crear las carpetas /dashboard, /invoices y /customers.

14 y 15. ¿Qué arrojó el localhost:3000/dashboard (Error 404)?
Arrojó un error "404 Not Found" porque la carpeta existía pero no contenía un archivo 'page.tsx'. Hemos visto estos errores cuando olvidamos crear el archivo principal de la ruta.

16. ¿Qué es el File System Routing?
Es el sistema donde la estructura de carpetas del proyecto define automáticamente las rutas de la aplicación sin necesidad de configurar un archivo de rutas externo.

17. ¿Cómo funcionan las rutas anidadas?
Se crean metiendo una carpeta dentro de otra. Por ejemplo, /app/dashboard/invoices crea la ruta /dashboard/invoices.

18. ¿Por qué es necesario el 'export default function'?
Es necesario para que Next.js reconozca esa función como el componente principal que debe renderizar cuando alguien visita esa página.

19. ¿Para qué sirve el componente <Link>?
Para navegar entre páginas de forma instantánea sin recargar todo el navegador (Client-side navigation).

20. ¿Qué se carga con <a> y que cuanndo se usa <Link>?
- Con <a>: El navegador refresca toda la página, descargando de nuevo todos los recursos.
- Con <Link>: Solo se descarga el contenido necesario de la nueva ruta, manteniendo el estado de la app.

21. ¿Qué es un Hook?
Es una función especial de React que permite "enganchar" el estado y otras características de React en componentes funcionales.

22. ¿Qué hooks usa Midu?
Principalmente usa 'usePathname' (para saber la ruta actual) y hooks de navegación como 'useRouter'.

23. ¿Por qué ocurre el error de la imagen (usePathname)?
El error ocurre porque se intenta usar un Hook (usePathname) en un Server Component. Los Hooks solo funcionan en Client Components. Se soluciona agregando 'use client' al inicio del archivo.

24 y 25. ¿Es posible ejecutar componentes en cliente y servidor?
Sí, Next.js es un framework híbrido. Por defecto los componentes son de servidor (Server Components), pero podemos definirlos como de cliente (Client Components) usando la directiva 'use client'.

26. ¿Qué es el code splitting?
Es una técnica que divide el código de la aplicación en paquetes pequeños. Next.js lo hace automáticamente por ruta, cargando solo el código que el usuario necesita ver en ese momento.
